Quick Guide: Phone, Tablet & Cloud

1. Install on Your Phone & Tablet

Open this page in Chrome (Android) or Safari (iPad/iPhone), tap the menu/share button, and choose Add to Home Screen or Install app. It works offline too!

2. Real-Time Sync Across Devices (Free Firebase)

  1. Go to console.firebase.google.com and create a free project.
  2. Enable Authentication → Email/Password and create a Firestore Database (start in test/production mode with your rules).
  3. Copy your Web App firebaseConfig, paste it into Cloud Sync here, and tap Connect & Enable Live Sync.
  4. Create/sign in with the same email & password on both your phone and tablet.

3. Export / Backup

Tap the Download icon in the top bar to save a standalone index.html file, or the Print icon to save a clean PDF/paper record for any pupil.
